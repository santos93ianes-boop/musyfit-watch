# MusyFit Watch T800 v3.1

Versão dedicada ao T800 Ultra2. Redmi e outros relógios foram removidos da busca.

## Conexão
1. Feche totalmente o HIwatch Pro.
2. Ligue o T800 Ultra2 e deixe a tela ativa.
3. Autorize Bluetooth no MusyFit Watch.
4. Abra a aba T800 e toque em Buscar T800.
5. Toque em Conectar. Se necessário, use Parear e confirme no celular/relógio.

O app só exibe "T800 conectado e validado" depois que a sessão GATT abre e os serviços são descobertos.
